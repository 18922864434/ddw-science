## 改动二：assets/css/ddw-main.css 末尾追加「历届大会（图文版）」样式块

全部使用 `--ddw-*` 令牌与站内既有惯例值，`.ddw-conf-*` 前缀（已确认全站无冲突），不写裸色值：

- **卡片**：白底 + `1px solid var(--ddw-border)` + 圆角 8px + `overflow:hidden`；hover `translateY(-4px)` + `box-shadow: 0 10px 24px rgba(14,77,140,.12)`、transition `.25s`（与 `.ddw-grid-card`/`.ddw-book` 完全同款）
- **桌面 ≥992px**：`.ddw-conf-item` 为 grid `55fr 45fr`；`nth-child(even)` 时媒体区 `order:2` 实现左右交错；`.ddw-conf-list` 垂直 gap 32px 保证五届节奏一致
- **图库**：媒体区 `aspect-ratio: 16/10`（按截图微调）+ `min-height` 兜底；gallery 内部 grid `1.6fr 1fr`、gap 8px；主图占满左侧高度、辅图 2 张各占 `1fr` 行（`aspect-ratio: 4/3`）；图片 `object-fit: cover`、无圆角（贴卡片边缘由卡片裁切）；辅图区写法天然兼容 3–5 张（自动增行/增列）
- **文字区**：`padding: 32px 36px`、flex 纵向居中；tag 行复刻 section-eyebrow 语言（accent 色 13px/600/字距）；h3 20px/700/primary；meta 标签 12px muted + 值 14px/600、flex 可换行；desc 14px muted/行高 1.8；链接 primary/600，hover 变 `--ddw-primary-dark` + 下划线 + 箭头右移
- **可访问性**：`.ddw-conf-link:focus-visible { outline: 2px solid var(--ddw-primary); outline-offset: 3px; }`（覆盖模板青色焦点环，与品牌一致）；`@media (prefers-reduced-motion: reduce)` 禁用卡片位移与箭头动画
- **响应式**（沿用站内断点写法）：
  - `max-width: 991px`（平板）：保持两列交错，缩 padding 至 24px、name 18px、desc 13px
  - `max-width: 768px`（手机）：单列——图上文下（DOM 本就媒体在前，取消 order）；主图全宽 `16/10`，辅图改横排（`grid-auto-flow: column` 等分）；body padding 20px；meta 自动换行，320px 宽度无溢出、无横向滚动
