## `scientist.html` 主题 UI 修复方案

### 1. 修复右侧卡片溢出这一根因
- 在 `scientist.html` 的“机构角色”右侧列增加语义容器类，例如 `scientist-role-cards`。
- 在 `assets/css/ddw-main.css` 中仅对该容器内的 `.ddw-grid-card` 设置内容自适应高度，覆盖公共卡片的 `height: 100%`。
- 将容器设为纵向布局并使用统一 `gap` 控制卡片间距，同时移除卡片上零散的 `mb-3`，避免 margin 与 gap 叠加。
- 不全局修改 `.ddw-grid-card`，以免影响首页四宫格、科学贡献卡等依赖等高布局的区域。

### 2. 按现有 DDW 主题整理“科学起源”区块
- 将最后的“科学起源”区块改为现有 `.ddw-section alt` 浅蓝交替背景，恢复全站白色/浅蓝色区块节奏，并与前一白底区块形成清晰分隔。
- 将该区块中不存在的 `var(--ddw-navy)` 替换为主题已有的 `var(--ddw-primary)`，确保小标题稳定使用站点主蓝色。
- 保留现有 `.section-eyebrow`、`.section-title`、正文排版与 Bootstrap `.container`，不新增第二套主题样式或独立容器体系。

### 3. 完善表格响应式表现
- 保留现有 `.ddw-table` 主题表格样式。
- 在“113 项出版物分类”表格外增加 Bootstrap `.table-responsive` 容器，使窄屏只在表格区域内滚动，避免整个页面产生横向滚动。

### 4. 验证与回归检查
- 启动本地静态页面，在桌面宽度重点确认：右侧 3 张机构卡片不再覆盖下一节、左右两列正常结束、区块背景交替正确。
- 检查 1440px、1024px、768px、390px 和 320px 等典型宽度，确认卡片在断点下正常堆叠、文字无截断、页面无横向溢出、表格可局部滚动。
- 回归检查人物简介卡、四张科学贡献卡及其他使用 `.ddw-grid-card` 的区域，确保局部覆盖未破坏原有等高效果和 hover 样式。
- 检查浏览器控制台与页面资源加载，并保留工作区中 `index.html`、`books.html`、图书图片及现有 CSS 的未提交修改，不覆盖或回退来源不明的并行改动。
