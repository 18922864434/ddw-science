## GSC「无法读取站点地图」排查（只读诊断，未改任何文件）

### 结论
服务端与文件层面全部健康，`sitemap.xml` 本身无问题；故障几乎可确定落在
**GSC 提交方式/媒体资源范围** 或 **Cloudflare 边缘策略** 两处。

### 实测证据（均通过 `curl --noproxy '*'` 直连取得，走代理会返回 000）
- `https://ddw-science.com/sitemap.xml` → **200**、`Content-Type: application/xml`、`Content-Length: 5870`、**无 `X-Robots-Tag`**、`cf-cache-status: DYNAMIC`
- 线上文件与本地 `sitemap.xml` **逐字节一致**（5870 = 5870）；`robots.txt` 同理（366 = 366）
- `robots.txt` → 200、`text/plain`，`Sitemap:` 指令指向正确，`Disallow` 未覆盖 `sitemap.xml`
- XML 解析通过；**27 条 `<loc>`，无重复**、无 `.html` 后缀、无 `www`/`http` 混用、`lastmod` 格式全部合法
- 27 条 URL **逐条实测全部 200**
- `http://` → **301** 跳 https ✓；HEAD ✓；gzip ✓；Googlebot UA ✓；空 UA ✓
- 连续 40 次请求全部 200，**无限流**
- 无 Cloudflare 拦截头（无 `cf-mitigated`），无 JS 挑战页
- TLS 1.2 与 1.3 均 200；证书 `CN=ddw-science.com`，签发 Google Trust Services WE1，有效期 2026-08-24 → 2026-11-22（当前有效）；TLS 1.0/1.1 已禁用
- **`www.ddw-science.com` → NXDOMAIN（该子域根本不存在）** ← 若 GSC 属性是 www 属性则必然失败
- 易错输入实测：`/sitemap.xml/`（尾斜杠）→ **404**；`/Sitemap.xml`（大写）→ **404**
- Google 验证文件 `googleeeb894935fed1c56.html` → **308** 跳无扩展名形态 → 最终 200（53 B），验证链未断

### 代码层面的既有偏差（非故障原因，属优化项）
- `xhtml:link` hreflang **只标了 11/27 条**（11 个主页面），15 个 `papers/*` 与 `/videos` 无标注；且均为**自引用**单语言形态 → 规范允许但 Google 会提示"缺少返回链接"，且站内声明不一致
- `changefreq` / `priority` Google 已忽略
- 除 `/videos`（2026-08-31）外，**全部 `lastmod` 统一为 2026-08-20**，缺乏区分度，长期会削弱 Google 对 lastmod 的信任

### 待人工核对（无法从外部探测）

2. GSC 中实际提交的 URL 字符串是否带尾斜杠或大小写错误
